# Cosy Breeze Theme For Nermity 🐈

- A fully customised and full fledged nermity theme that attempts to improve on the usability, style, customisation and polish of the default client.

- It currently is being supported for both desktop and mobile.

- Please open up an issue if you encounter any bugs, flaws or inconsistancies with the theme.

##  How To Apply The Theme & Colour Scheme 🔗

### Theme 🖼️

Paste this into the CSS section of Nerimity to apply the theme.

- You can find this under Settings - Interface - Scroll down to the bottom - Custom CSS.

- Paste the code below here and then press Save & Apply to apply the theme.

```
@import url('https://weescottishman.github.io/CosyBreezeTheme/CosyBreezeTheme.css');
```

### Custom Colour Scheme 📐

You can also make your own custom colour scheme with no CSS involved.

- To do this first go to Settings - Interface - Scroll down a bit.

- Change any colours you want using the eye dropper box and the theme should update automatically.

- There are also community made colour themes at the top of this page that will also work.
